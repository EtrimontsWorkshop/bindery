## [0.6.0]

### Security

- **pdf.js updated from 6.1.200 to 6.4.299.** The bundled version had a known flaw (GHSA-hq66-cqwq-w95j) that let a crafted PDF run JavaScript when it was opened. Since 6.2 pdf.js names a PDF's fonts only on request, so Bindery now asks for it (`fontExtraProperties`); without it every font was anonymous and the layout analysis lost the fonts' roles.
- **zod updated to 4.6.7.** zod 3 could run out of memory while validating a profile with an oversized collection (GHSA-mrhx-c7xc-m3w5).

### Added

- **A setting for the storage of uploaded images.** Images went to Foundry's user data storage only. "Image upload storage" now also offers Amazon S3 (with "S3 bucket") and the hosting service's assets library; the default is unchanged.

### Fixed

- **A release's manifest downloads that release.** The manifest's download link pointed at "the latest release", so the manifest of an older version fetched the newest zip. The built manifest now names the zip of its own version (the update check still looks at the latest release).
- **Page numbers follow the interface language.** "p. 12" was written in English in the review list, in diagnostics and in the default names of imported images; in Polish it now reads "s. 12". The message for a profile file that is not valid JSON is translated as well.
- **A slow pattern in a statblock profile is refused.** A pattern with several repeats in a row that match the same characters (`\w*\w*\w*!`, `.*\d+x`) passed the check that guards against patterns that never finish, and one line of a statblock could hang the page for seconds or minutes. Such patterns are now refused when the profile is used, like nested repeats already were; start the pattern with `^`, or separate the repeats with a character they cannot match.
- **A profile cannot write outside the actor's own fields.** A field path naming an object's prototype (`__proto__`, `constructor`, `prototype`) is ignored.
- **An import never replaces a file that is already in the upload folder.** When the folder could not be listed, Bindery assumed it was empty and uploaded under the first name, replacing a file of that name without a word. The files of such an import now get a suffix of their own. A name that the listing gives URL-encoded is recognised as taken, too.
- **File names keep letters of every alphabet and stay short.** A name in Cyrillic, Greek or Japanese was reduced to "image"; letters and digits of any script are now kept (Latin letters still lose their accents). The base name is cut at 60 characters, so a long caption no longer makes a name the file system refuses.
- **A scene whose background could not be set is removed.** The scene is created first and given its image second; when the second step failed the empty scene stayed in the world, and importing again added another beside it.
- **Cancelling the grid window leaves the scene out.** It used to create the scene anyway, with the grid of the previous scene. The scene is now skipped (nothing is uploaded for it), the summary says so, and pressing Import again asks for its grid again.
- **"Import complete" is said only when it is.** An import in which some or all items failed ended with the same success message. The message now tells how many were created and how many failed, as a warning, or as an error when nothing was created.
- **A crop belongs to the page it was drawn on.** Turning the page while a crop or a resize was being rendered could take the picture from the new page.
- **A picture cropped again is an ordinary picture again.** A picture edited by hand keeps its transparency under the "white background" setting; resizing its frame renders it from the page anew, without the edit, but it was still treated as edited.
- **The legal notice counts as read only when confirmed.** Closing it with the window's X recorded it as acknowledged.
- **A large custom token frame is not stored in the world's settings.** "Set as default" saved the frame file with the defaults, and every player's browser downloads those settings on joining. A frame over 1 MB is still used for the token at hand, but the defaults are saved without it, with a notice.
- **A page too dense for the search for vector drawings is reported.** A page with more than 20,000 vector shapes was silently left out of that search; the diagnostics now name it.
- **A long book no longer fails at the text analysis.** The spacing statistics of a font took their largest value with a call that passes every gap as an argument; a font with more than about 125,000 gaps (a thick book whose text is stored word by word) overflowed it, and the whole import ended with "Could not build a preview". The largest gap is now found with a loop.
- **A double click on Import does not import twice.** The button is disabled only once the window has been redrawn; a second click before that started a second import beside the first, creating every scene and journal twice.
- **The import window opens once.** Each press of the menu button created a new window with the same id, which took over the first one's place on screen while the first kept analysing unseen, and allowed a second review to open over the first. The window that is already open is now brought to the front.
- **Closing the import window stops the analysis at once, and the progress covers all of it.** Of the three passes over the PDF only the last one (the images) listened to the cancel signal and reported progress: closing the window during the first two left them running, and the counter stayed empty. All three now stop on cancel and report into one percentage, redrawn once per percent rather than once per page.
- **Foundry imports pictures stored in tiles as they are imported everywhere else.** In the browser pdf.js hands a page's decoded images over a moment after its list of operators, and the inventory read them at once: no image had a content fingerprint, so the tiles of one picture were never joined across a seam (a cover cut into six tiles came as three pairs) and a box of text was cut short. The inventory now waits for them, a few pages at a time while it goes on with the next ones, so the wait costs little time. The page-filling images that may be the book's paper are fingerprinted after the pass over the pages: read during it, they changed which images pdf.js shares between pages.
- **A picture cut into bricks comes whole.** A scene stored as rasters of different sizes laid like bricks, slightly over one another (some cut short by a clip), most of them too small to be offered by themselves, came as two of its pieces. Rasters of one pixel density that meet or overlap a little and together cover the rectangle of their union, with an offered picture among them, are one picture; a piece of the page's paper at the page's edge is not taken in.
- **The book's paper embedded once more is not offered as a page.** A title page set on its own copy of the paper the book repeats on other pages (the same content, a logo laid over it) was offered whole, together with the facing page; it is the page's background, and the logo and the portrait opposite come by themselves. A sheet built of many pieces laid on that paper (a character sheet) is offered as before.
- **Pieces of the page's paper are not offered.** The corner of the page with its shading, laid over the page as a raster or as a few tiles, and a chapter's page whose paper is cut into tiles under its text, were offered as pictures (the latter as a whole page among the images with text). Light rasters that run off two edges of the page, each a small part of it, with no text over them unless they make up the whole page, are hidden.
- **A photograph laid aslant comes upright, without the page's text.** A picture painted tilted on the page as two rasters turned alike (its left and right parts) was rendered from the page as it lies there: aslant, with lines of the text round it. Its pieces are now laid side by side in their own frame, upright, from their own pixels.
- **A map and the drawing below it come apart.** A plan stored as tiles and a drawing in a torn frame painted as a few clipped strips, set edge to edge, came as one render with the page's text beside them: no piece was large enough to count as a picture of its own. The tiles are one picture and the strips another, taken from their own pixels laid over one another.
- **A strip of a drawing is not offered beside the drawing.** A piece of a picture left out of its group (the bottom strip of a drawing), set edge to edge with a raster of that picture and lying within the region already rendered for it, was offered again by itself. A picture that merely lies within a rendered region (a logo in a frame) is still offered.
- **The picture within an ornamented frame is offered, not the frame.** A page-sized illustration whose border is a raster of its own, painted over it and transparent within, was offered as the empty frame: the picture under it was taken for covered by it, or taken into one unit with it. A frame that is transparent over its middle now gives its turn to the picture it frames.
- **Props tossed over the page's edge are not offered as pictures.** A book whose pages are strewn with photographed props (dice, poker chips, playing cards, claw marks, bullet holes), each laid half off the page, offered them all among the pictures. A cut-out object on a blank ground (transparent or white over half of it at least), half a page at most, with a fifth of its box or more off the page, is now hidden as a prop of the page's design, unless it reads as a document (a typed memo laid over the edge stays). Such props count among the book's ornaments of one colour too, so a red circle drawn round a word beside red dice stays hidden. In a book strewn with them (fifteen such props at least, offered but for this: objects, not strips along the page's edge, nor hidden pictures looked at once more; two books strewn with props have about thirty, thirty-five others nine at most), the cut-out objects on a blank ground are props too, wherever they lie (a die in a corner, coins, a key, handcuffs, a magnifying glass, a strip of torn paper): blank over 55% of the raster at least (transparent, or a light paper nearly without colour: the off-white of a torn strip or a blank card counts), covering a third of the page at most once its blank ground is left out. Those books draw their illustrations opaque. A prop that the page renders (paired by mistake with another across the gutter, or turned) is judged by its own raster; one rendered with the page where no text of the page lies over it (a hole torn in paper) is judged as rendered. A faint stain of the paper in a corner, rendered with the cards of text laid over it, is hidden too when its own raster is nothing but paper (never the page's paper itself). A prop taken whole from its own raster is judged so even when it overlaps another (two splatters laid one over the other). The frame of a box of text is also found when its paper within is white and its header bar is tall, or when it is one flat colour (a dark header bar with the page's heading over it), and in a box of a list that the page's text fills, whatever the box was taken for; never a half of a picture across a spread.
- **The frame of a box of text is not offered as a picture.** The background of a sidebar, stored in pieces (a header bar and thin sides, transparent within), was offered as a picture whenever the sidebar's text ran past the piece: text that runs past a picture is the page's own, so the piece was taken from its own pixels. A raster under the page's text that is transparent over most of it, with next to nothing visible within its edges, is now hidden as the frame it is. A frame of thorns round a whole page of text is hidden as well.
- **Different pictures in the same place of the layout are no longer taken for one ornament.** A book whose chapter openings put a different illustration in one slot of its template (same size, same place on the page) had those illustrations linked as one picture repeated on many pages and hidden as a running ornament. Pictures in the same place are now linked only when their content is alike too (a tiny 8×8 picture of each image is compared, taken while the PDF is read); a picture embedded again on every page (a frame, a footer ornament) is still recognised.
- **Pictures that the text wraps around are offered again.** A portrait set between two columns, with the lines of both columns cut short beside it, has the boxes of that text over it, and was taken for a backdrop under text and hidden. Bindery now also reads where the words of the page lie (as the PDF gives them, before they are grouped into lines): when no word lies on the middle of the picture, it is offered as undecided. On 18 books this brought back the 14 portraits of one adventure and three pictures of three others, and hid nothing that was offered before. The few such portraits that come with their ornamental frame are cut out from the page, with the ends of the wrapped lines in their corners (the image editor can erase them).
- **A note or a box of text comes with its text.** A card whose text the page writes on blank paper (a handwritten note, a sidebar on a coloured panel) was listed among the images with text as its paper alone, because the paper is the picture the PDF stores. Such a card is now taken as it shows on the page, its text on it, and two notes written on the same paper are no longer taken for one picture.
- **A picture painted over a card of text is taken off the card.** A stat block on a sheet of paper with an illustration painted over its corner came with that illustration in the images with text; the card's own paper is now put back where the illustration lies (the illustration is offered by itself), unless words of the page lie there.
- **A bare sheet of paper under a drawing is not offered.** A drawing painted on a page as two images, the sheet of paper first and the drawing over it, offered the empty sheet as an image of its own; a plain sheet with a picture of the page painted over a third or more of it is now taken for that picture's backdrop. A sheet laid on a darker ground that shows round its edges (a page's paper) is judged by its middle.
- **A page that is a document is offered among the images with text.** In a book whose pages share one background, a page with a sheet of paper of its own and text written on it (a letter, a page of a diary) was hidden as a page background. It is now offered, with its text, among the images with text; a page with its own illustrations, a white page or a page of art stays as before.
- **A table drawn with vector paths is not offered as a drawing.** With "Import vector drawings" on, a table on striped rows (or a plate of text, a heading drawn over a texture) could be offered as a drawing. A cluster of paths that the page's words lie on (a twentieth of its box or more) is now left out; the drawings found in 20 books have no words on them. Nor is a grid of boxes of one size (the tick boxes of a character sheet): a cluster with four fifths or more of its shapes of one size is left out.
- **The edge of the page's design is not offered as a drawing.** With "Import vector drawings" on, a chapter tab or the lettered backdrop of a page, whose paths run past the page's edge, could be offered as a narrow strip of the page (with white beyond the page's edge). Paths past the page's edge are now left out, and a cluster of paths that runs past the edge and is cut by it to a band narrower than a seventh of the page is not a drawing. The ornaments of a page's design are left out more surely too: a cluster of paths that runs past two edges of the page (a swirl in its corner, a band down the whole of its margin) is not a drawing however wide, a band past one edge is not one up to three tenths of the page (a swirl beside a heading), and a drawing found at the same place on three pages is a running ornament even when it is drawn with a few shapes more or less from page to page.
- **The backdrop under a card of text and a photograph is not offered.** A page's texture painted under a sheet of text and a photograph came, rendered, among the images with text: the sheet's text and the photograph again, both offered by themselves. A rendered picture whose words all lie on the boxes painted over it, and which those boxes cover for three fifths or more, is now taken for their backdrop; a picture with a box of text in its corner is covered far less and stays.
- **A printed sheet or a postcard lying at the edge of the page is offered.** A sheet cut out by a mask (its drop shadow) and running off the page (a poem at the foot of a page) was hidden with the paper scraps and stains that run off the page. Such a sheet is now looked at once more and offered, among the images with text, when its pixels are a document; a print that only touches the edge of the page (a postcard laid at its head, 6 pt over the edge at most) and is not plain paper is offered as a picture. The stains and scorched corners that bleed off the page run further past its edge and stay hidden.
- **A picture stored in tiles comes whole.** A map (or an illustration, a card of text) that the PDF stores as several rasters set edge to edge was offered as its pieces: the plan, a strip of its ground, a panel of its legend. Pictures that abut along the whole of a side, within a few points, and whose content runs on across the seam (read from the tiny picture of each taken while the PDF is read) are now one picture, rendered whole. Two pictures of their own set edge to edge, such as two frames of a comic, differ across the seam and stay apart. On one book of the corpus this also brings back whole the figures, maps and cards that came cut into strips. Tiles laid like bricks, whose seams do not line up from row to row (an advert cut into four rasters and a strip with the tops of its letters), are one picture too when together they fill a rectangle; a strip too small to be offered by itself is taken in as one of its tiles. When some pieces of such a set belong to the page's design instead (the ends of a frame under a box of text, leaving a hole in the rectangle), the largest part that fills a rectangle is the picture and the rest is left out. In Foundry the tiny picture of an image the browser decodes itself was read from a few of its pixels only; it is now the mean of each part of the image, as for the others.
- **A dark map with a small picture on it is not taken for a panel behind that picture.** A map painted translucent, with a neon sign laid on its corner, was taken for the dark panel of the page's design behind the sign, and only the sign was offered. A dark texture is now a panel behind a picture only when the picture is a quarter of its size or more.
- **A plan drawn in lines over tiles of texture comes as the plan.** A book of maps that draws its floor plans and buildings in stroked lines over tiles of a dark texture offered the tiles: the bare texture, a plan cut at a tile's edge, a building hidden as a backdrop. Bindery now also reads the stroked lines of the page (only filled shapes were read). A cluster of many touching lines lying over the page's pictures is a line drawing, and it replaces the tiles it lies on: one picture per drawing, rendered over its box and over the tiles it covers for the most part. A drawing over two tiles is one picture; a plan on one tile and a building on the next, their lines touching, are two. A tile no drawing covers is hidden when it is a bare dark texture. The rules of the layout's frame, the lines left past the page's edge and the rules of a table (a cluster that the page's words cover for a quarter or more) are no drawings.
- **A bare sheet under a drawing in several pieces is hidden as before.** A page background is taken for the backdrop of the pictures painted over it when they cover a third of it together, not only when one of them does.
- **"Remove numbers from maps" also removes coloured square markers.** The option painted over only black discs with a white number. A map whose key is drawn as squares of one colour with a light number in them (red squares on a drawn fortress) kept them. Three or more such squares of one size and one colour, solid (their colour and their number fill nine tenths of their box) and closed all round in their colour, are now painted over too, each filled from the ground at its four edges, so that the shading of the drawing goes on under it instead of a flat patch. The red labels and lines of the same map, the bold red letters of a headline (an O, a D, an E: round corners or gaps open to their edge) and the patches of colour of other pictures are not squares and stay; on the corpus, at the resolution of an import, only this map is touched.
- **The ornaments of a book's design are hidden.** A book that draws its drop caps, flourishes, seals and frame strips in one colour of ink (red, on blank paper) offered them as pictures, dozens per book. When six or more of the pictures nobody could judge are line ornaments in one saturated colour (sparse ink, one hue), that colour is the book's ornament colour, and they are hidden with its decoration, together with the thin strips of its frames (3.2 times longer than wide or more, sparsely inked in one colour). The book's sepia portraits and its paintings are other colours or many, and a book with a red seal or a red logo or two keeps them. On one book this hides 35 of its 90 pictures, all ornaments; on the corpus, three red ornaments of a book from the same series.
- **A picture across a spread comes whole when one half is stored in pieces.** A scene whose right half was two masked rasters at the page's edge, overlapping and blending into each other, each over part of the height, came as its left half alone: each piece, looked at as a figure at the edge, lined up with nothing. The pieces on one page that overlap one another now make one half over their joined box, laid over one another from their own pixels in the order the page paints them (without the page's text set over them), and joined to the half on the facing page that lines up with it. So too a picture stored in pieces side by side on one page: an offered masked raster with the masked cut-outs beside it that overlap it over most of its height and widen it by a third at least (hidden at the page's edge) is now one picture of their own pixels laid over one another, joined to a narrow strip of it on the facing page as well (an edge strip of 3% of the page is enough beside such a half). On one book this completes five pictures that came without a piece or a strip.
- **A scene across a spread comes whole when a column of text ends on its mist.** A scene running across the gutter, whose faded top on the left page carried the last lines of a column, came as two pictures: the left half, rendered with those lines, held text and was no half. The rows of such a half are now cut clear of a column of the page's text that runs over its top or foot (the blocks that cross that edge and the paragraphs set on under them, within a fifth of its height); the right half takes the same rows, and the two are joined. Labels inside a picture (the numbers and names on a map) cross no edge and are left.
- **A drawing set in the middle of a page comes without the columns round it.** A sketch on white paper set between the two columns of a page, the columns wrapped round its blank corners, was rendered with their lines and the page's border; the render did not read as a document, so the picture was not taken from its own pixels. Now the page's text running past the drawing's edge is enough as well: a drawing (its luminance spreads) white under the page's words is taken from its own pixels, without the text. A drawing of a ring that came only among the images with text is now offered by itself as well.
- **The halves of a picture across a spread are joined in more of the ways a book stores them.** A search of eleven books of one series found pictures across a spread offered as one half: the other half, a strip at the gutter, had been hidden (as a narrow strip, a stain, or a picture of no interest) and was never looked at as a half; a map's right half that the page writes its labels over was a box of text, and a box of text is no half; line art with next to nothing drawn at the gutter gave the check of the seam nothing to compare; and a half cropped to its visible part no longer lined up with the other. Now a hidden picture that lines up with an offered half on the facing page stands for its other half (it is never offered by itself); every left half waits for its right half, offered or not; a half the page writes over is joined by its own pixels (and stays among the images with text as well); two rasters of one height in pixels placed at one height are taken for one raster cut in two, joined whole even with a blank seam; and the joined picture is judged as the larger half looks and offered as its offered half was. A half that is all transparent (the empty margin of a masked picture beside a picture of the facing page) is not joined. On those books this joins 28 more pictures; elsewhere a shoulder across a spread comes whole and a picture no longer takes a transparent margin with it.
- **A picture across a spread comes whole when one half is cut out by a mask at the page's edge.** A drawn tower whose narrow left half ran along the edge of one page and whose larger right half, cut out of the paper by a mask, began at the edge of the next was offered as the narrow strip alone (and a map of a mine, the other way round, as its right part): a masked picture running off the page is hidden with the stains and scorched corners, and looked at once more only as a figure of its own, never as a half. Such a picture is now a half of an offered half on the facing page that lines up with it, and the two are joined, offered as the offered half was.
- **A map laid aslant across a spread comes whole.** A map turned on the spread, cut by each page, came as its larger half and a sliver on the next page: the boxes of the two turned rasters do not line up. A raster that runs past the right edge of a page and one on the next page that runs past its left edge, at overlapping heights, are now the halves of one picture when what they show (their ink inside their clips) runs from within the first page to the gutter and from the gutter to within the second, with few of the page's words on it: each is rendered over what it shows, at the same heights, the right one up to where the page's text begins, and the two are joined. A picture across a whole page or a card of text laid aslant is no half.
- **A map across a spread comes whole when a picture lies beside its half.** A map whose narrow left half ran along the edge of a page next to a portrait came as two pictures: the half was grouped with the portrait, and the group, taller than the map, did not line up with the other half on the next page (the two were split apart again only later, by their pixels). Such a half is now paired by the box of its own raster, and the halves are joined as any other.
- **A page with an illustration blended into it is not offered as a document.** In a book whose every page has its own parchment, a page with a sword multiplied into its paper was taken for a document (a letter, a page of a diary) and offered whole among the images with text. An illustration blended into the page now makes it a page of the book too, when it covers 15% of the page or more (a stain or a strip of tape over a letter is smaller); the page's paper is hidden and the sword is offered by itself.
- **A drawing with the page's text set on its blank part comes by itself.** A sketch filling half a spread, with a column of the chapter set on its white part, was rendered with that text and, reading as a document, offered among the images with text. When the render reads as a document but the raster does not, the raster is a drawing (its luminance spreads) and it is white where the page's words lie, the picture is now taken from its own pixels, without the text. A newspaper or a sheet the text is printed on (tinted under the words) and a sidebar on a dark panel stay with their text.
- **A figure cut out of a transparent ground is not taken for a sheet of paper.** A character drawn on a transparent ground that fills two thirds of the page, the page's text set in that ground beside the figure, was taken for a sheet of paper with the text written on it, and offered among the images with text as the page shows it. A sheet to write on is now opaque over most of its raster (three fifths at least); the figure is offered by itself, from its own pixels.
- **Drawings laid one over another come without the text beside them.** Two drawings on white paper laid over one another (blueprints and tools) are rendered together from the page; where the white of a raster reached over the page's text (the last rows of a table above them, the page number beside them), the render carried that text. Such a render is now cut to what the drawings show (their ink against the paper of their edges, or what is not transparent), and clear of a word across its side, when that leaves the text out. Only for drawings on light paper with a few of the page's words over their box (2-15%): a card of text, a cover on a dark ground or a figure with no text by it is left as it was.
- **Items drawn side by side come apart.** A page of equipment whose items are cut-outs on a transparent ground (a staff, an axe, a dagger, a bow, a shield), their boxes overlapping where the drawings do not, offered pairs of them as one picture, rendered with the page. A large picture of a group (a tenth of the page or more) was never told apart from the others by its pixels; it now is when most of its raster is transparent, so each item comes by itself, taken from its own pixels. A large opaque picture stays with what lies on it, as before.
- **A picture stored as a grid of small tiles is offered.** A portrait that the PDF stores as rows of small rasters of one size (9 rows of 5, each under a hundredth of the page) was not offered at all: each tile was too small to be offered by itself, and tiles were joined only to a picture that was. Six tiles of one size or more, set edge to edge and filling their rectangle (a narrower last column or row with them), are now one picture, rendered from the page and cut clear of a name set in large letters across its edge. On one book this brings back 38 pictures: the logos of the companies on its item pages, and items stored the same way. A grid that renders with the page's text is the boxes of a form and stays hidden.
- **A picture painted in slices comes whole.** A picture that the PDF paints as many pieces, each cut out by a shaped clip of its own (a weapon as the slices of its blade, its hilt and its tip, on a page laid out as a shop's screen), was hidden: on a page crowded with small pictures its pieces were taken for the parts of a form, and the few large ones were split apart, each a strip of the blade, while a piece cut along a line of the text came, rendered, among the images with text. Such pieces are now one picture, rendered over what they show (inked in their rasters, which are often turned, and inside their clips, a few points wider), not over their rasters, which run far past it over the heading and the text. A piece cut along the text that shows nothing outside the picture is left out. A picture in a rectangular frame is not a slice. A small picture painted as three or more strips laid aslant (a sword along the margin of a column of text) is rendered the same way, over what its strips show: rendered over the boxes of its turned strips, it came with the ends of the column's lines.
- **A cover comes with its text.** A page that is one picture with a few lines of display text over it (the cover of a magazine handed out as a prop) was hidden as a background with text, or offered as its picture alone, without the title and the headlines. Such a page (a picture filling it, 100-800 characters of text at 18 pt and more on average; a chapter opener, credits or a comic page have smaller letters) is now offered among the images with text, as the page shows, turned the way it reads. A picture the classifier was sure of is offered as before.
- **A card of a handout comes whole.** A set of handouts whose cards are drawn in a frame of rules (a personnel record: photographs, a row of fingerprints and the fields of a form, to be cut out along the frame) offered only the photographs and a fingerprint. A frame of rules (rules of one width at its top and bottom between two vertical rules) that fills half the page or more, with two pictures in it at least and a few lines of text, is now a card: it is offered whole among the images with text, as the page shows it. Its pictures are offered by themselves as well.
- **The corners of a panel's frame are not offered.** A panel drawn with ornamental corners (one small picture painted at each corner, mirrored) offered each corner as a picture. A small picture that a page paints both as it is and mirrored is now an ornament of the layout; one repeated in one orientation (a sheet of tokens) is judged as before.
- **A plan cut out by its frame is offered.** A big picture cut out by a mask that filled 70-75% of the page (a ship's plan in a frame) was taken for the page's background; such a picture is now an illustration, and of two masked layers of one picture in the same place only the first is offered. When such a plan runs across a spread, its two halves are joined into one picture again: the second unit made for a picture at the page's edge no longer takes the half's place in the pair.
- **Cards of text are turned the way they read.** A letter or a telegram that the book sets sideways, or a note lying askew, was offered as the page shows it. A box of text, and a rendered picture that the page's words cover a good part of, is now turned so that its text runs left to right: by quarter turns exactly, by any other angle resampled onto a canvas that holds all of it. The direction is the one pdf.js draws the text in, read from the text on the card; a card whose text is drawn into its picture, or with too little text, is left as it is.
- **A sheet of paper with the page's text on it is offered with the text.** A book that gives a page (or a note) a sheet of paper of its own, and writes its text on the sheet, offered the sheet as a blank image. A light sheet with little text of its own (the scraps of the sheets under it that show at its edges), with the page's words over a sixth of it or more, all of them on the sheet (the text of a page running over a patch of its paper texture runs past its edges), and not drawn over with vector paths (a map on its paper is a map), is now a box of text, rendered with its text.
- **A page of documents is offered among the images with text.** A picture that is a page of typed or handwritten sheets laid over one another or askew (a letter on a report, a page of a diary) was offered as a picture: few of its lines run across it, which the documents found so far have. Such a page is now told by its many lines of letters on light paper whose letters are of one size; the marks of an engraving and the labels of a map that lie on as many levels are of many sizes. Measured on 288 pictures of 23 books with many lines: the pages of documents and a few scanned pages of text are taken, the engraved portraits, hand-drawn maps and town plans are not.
- **Two facing pages are not joined into one picture when one of them is a page of text.** A page with a photograph beside a page of documents was joined into one picture across the gutter, because the edges of both pages at the gutter looked alike; a half that is a box of text is now a page of its own.
- **A photograph laid on a page of documents is cut out of it.** A picture that holds documents and a photograph in one (a snapshot clipped to a report) was offered whole. When the rest of such a picture, the photograph left out, is a page of documents, the picture now goes with the boxes of text and the photograph is offered by itself, cut out along its box (a tilted photograph keeps a sliver of the documents at its corners). The photograph is found in the pixels: the strokes of letters are blurred into their paper, and what stays dark or coloured, big, compact and not flat (a redaction bar is flat) is the photograph.
- **A document under a photograph goes with the boxes of text.** A memo with a photograph laid over two thirds of it was offered as a picture: what shows of it has too few lines to be a page of documents. A raster with a good many lines of letters of one size on light paper, with a picture of the page painted over two fifths of it or more, is now a document under a picture: it is offered among the images with text, whole as the PDF stores it, and the photograph is offered by itself as before.
- **A print laid askew on the page is offered straight.** A photograph or a painting that the page shows tilted, cut out by its mask, came out as a tilted rectangle with transparent corners. Its angle is now read from the edges of its outline that are not the raster's own, the picture is turned by it and cut to the largest rectangle of its visible pixels. A print whose corner shows is straightened from 1.5 degrees; one with a single side showing only from 5, so that an upright picture with one edge cut on a slant by the page's design stays as it is.
- **Handwritten notes and fanned stacks of documents go with the boxes of text.** A sticky note or a card in large handwriting was offered as a picture: its words are joined letters, too big to be taken for lines of text. Such a note is now told by a few evenly spaced rows of word-size marks of about one size: large for the picture, or, in smaller writing (a few lines with a circle drawn round them), holding almost all of the picture's ink; the numbers on a floor plan, a poster's lettering and a logo are smaller, of many sizes, or have much ink besides. A stack of sheets fanned askew, whose lines run slanted across it, is told by its many lines of letters of one size on paper that is almost all light; the maps, plans and scanned pages with as many lines are darker.
- **A second review no longer leaves the first one behind.** "Open review" could be clicked again while a review was open (also from a wizard closed and opened again); the new window took the place of the old one, which never closed and kept the whole PDF in memory. Only one review is open at a time now; another attempt brings it to front.
- **The PDF opened for the page preview is released when opening the review fails**, instead of staying in memory until the page is reloaded.
- **Another file cannot be picked while a PDF is analysed, built or reviewed.** Doing so could label the first file's journals and images with the second file's name.
- **Retrying a failed import does not create the documents again.** What an attempt already made (scenes, journals, groups, tokens, actors, uploads) is skipped by the next one. The review window cannot be closed while an import runs.
- **Polish letters stay in the names of uploaded files** ("Księga" was saved as "Ksie_ga").
- **The page overlay of the review no longer piles up resize observers**, one per page shown, each holding the old page image.
- **Statblocks: changing the profile while the PDF is read** reads it once, and the rows always belong to the profile chosen last; closing the review stops the reading.

### Changed

- **The analysis reads the PDF twice instead of three times.** The text layout needed a whole pass of its own over the document; it is now gathered while the inventory walks the pages (which reads the same things from each page), so a third of the parsing is gone. The progress percentage covers the two passes that are left.
- **Pictures are measured without reading them back again and again.** Every question the image analysis asks about a picture (how bright, how opaque, where its visible part ends) read the whole bitmap back from a canvas, several times per picture, and even its size was taken that way. The size is now read directly, and the pixels of the last few pictures are kept between questions.
- **The white background is put on before a picture is encoded.** With "Add a white background" on, every picture was encoded, then decoded, filled and encoded again (losing quality twice for WebP), and decoded a third time when saved. The analysis now fills the decoded pixels once, and saving skips pictures it already knows are opaque.
- **The review list shows small thumbnails.** Each row displayed the picture itself, so the browser decoded every map at full size as its row scrolled into view. A small copy is now made once per picture; the enlarged look on hover still shows the picture itself.
- **A page preview is rendered once.** Each redraw of the review window while a page was being rendered started another render of the same page and discarded the previous one. A page that finishes after you have turned away is kept for when you come back.
- **Journals of the whole book are not built while they are switched off.** The review has not offered them for some time, yet every import still laid the whole text out as journal pages.
- **Less copying of pixels**: a picture is no longer copied before it is encoded, and a decoded RGBA picture is copied in one block.
- **Development.** CI now checks the Foundry layer's types and the built manifest, and a release is refused when its tag does not match the manifest's version. `npm run build:dist` builds without copying the result into the repo root (CI and releases use it; `npm run build` still copies, and no longer rewrites the root `README.md` and `LICENSE`). Both packages build with Vite 8, the Foundry types are those of v14, and `globals` is a declared dependency. `buildImageExtraction.ts` (4,300 lines) is now a short orchestration: its rules are in five `extraction*.ts` files, the plan made before the first page in `planExtraction.ts`, the work on a page in `extractPage.ts`, and the extraction of one unit, in five phases, in `extractUnit.ts`. The review screen's import run, thumbnails, page previews, page overlay and image rows are in `review/`. The statements were moved, not rewritten; no behaviour changed.

- **Uploading is much lighter on the server.** The upload folder is created and listed once per import instead of once per image (about a thousand fewer requests for two hundred images), and a picture already given a white background is not decoded a second time.
- **The Foundry layer has unit tests** (`packages/module/test`), run by `npm run test` together with the core's.

## [0.5.0]

### Added

- **Numbers can be removed from maps (module setting).** The floor plans of an adventure carry numbered markers (black discs with a white number in them, the key to the rooms), drawn into the picture. With the new module setting **Remove numbers from maps** on, a picture that has at least three such discs of one size has them painted over with the color around them. A disc is found as a round, solid black blob (thick walls and lines do not have such a core) that holds a white number: the pure black inside, the white number and the light ground around it are all checked, and the oval counters of bold letters do not count, so pages of text and illustrations are left alone (twenty-three books were checked: the pictures changed are the 30 maps of one adventure). The part of the drawing under a marker is lost, and a marker that sits between thick walls or lines may remain (on the map that was tried, 14 of 19 were removed). Off by default.
- **Boxes of text have a sub-tab of their own in the review.** The boxes and cards of text that Bindery hides as the layout's own text (notes, letters, sidebars, stat blocks on parchment) are now kept with the analysis, marked as holding text, and listed in a sub-tab "Unassigned images with text" (shown only when the book has any), unchecked. Assigning one a destination moves it to that destination's sub-tab like any other image. No new analysis is needed, and they are never embedded in the text of the journals.

### Fixed

- **More boxes of text are recognized as such.** A note or a letter that the page's text covers over half of, or a quarter of on light paper, with the text on its middle, and a plain form with text over a third of it, were offered among the pictures when the classifier had not named them cards of text. They now go to the sub-tab of unassigned images with text. A darker picture with labels (a map) and a cut-out picture that the text wraps around (shown through the outline of its subject) are still pictures.
- **A form or a table that is a picture with its text drawn into it is not offered among the pictures.** A filled character sheet or a table of a handbook has no page text to find, so its pixels are read: many lines of small print on light paper ruled along the axes put it in the sub-tab of images with text. Floor plans (a few labels), maps on parchment and illustrated sheets are still pictures.
- **A newspaper or a page of a document that the page's text fills is a box of text.** The text covered most of the render and of its middle, but the high contrast of the print kept it from being told apart from a picture.
- **A shadow laid over the page is not a picture.** A big picture cut out by a mask whose raster is an even, nearly black texture and that reaches off the page edge (it showed up as a render of the page with a white half) is a decoration.
- **Splatters of blood or paint laid on the page are not offered as pictures.** A raster that is mostly paper, with ink of one saturated hue thrown on it as a blot and many separate droplets, is the page's decoration. Black ink counts too, when the ground is transparent or white and the droplets are many. Flat icons, creatures, figures in one colour, and codes are still pictures.
- **Tracks of tick boxes (stress, wounds) are not offered as pictures.** A raster in which a few dozen flat boxes of one size fill a quarter to a half of the picture belongs to the character sheet. Maps under a grid, which have either far fewer or far more cells, are still pictures.
- **The print at the bottom of a stack of pinned photos is not offered.** A photo pinned tilted to the page that another tilted photo lies over (painted later, not blended) was offered as a strip of the one above it. The big masked picture that was offered only as a possibility now hides it too, when both are pinned prints.
- **The second page of a character sheet is read as text in a picture too.** A raster that is ruled along the axes on very light paper, with too little print to be a form by itself, is taken for one when a form read from pixels lies on the same page. Floor plans, which measure the same, stay pictures.
- **A note pinned over the foot of a photo is no longer part of the photo.** The photo was rendered with the top strip of the note that the page paints over it, and the note was cut where the photo's box begins. What lies on top is now left whole, and the other one is what it leaves of it (decided by the order in which the page paints them).
- **A photo with notes pinned over it is offered as a photo, and the notes as boxes of text.** A dark, textured raster that page text lies over only at its edges (a print on a cork board) was hidden as a card of text, or rendered with the notes on it. It is now taken from its own pixels and offered as a picture. Notes with text on them are no longer taken for the elements of a form because their page is crowded with pins and masks.
- **A map with labels laid over it by the page is offered without them.** A picture that is darker than paper and has a texture (a map), with the page's text over it only here and there, is taken from its own pixels, as the other maps of a book are, instead of as a render with the labels on it. A light card of text, or a dark backdrop with text over its middle, is not taken for a map.
- **A photo in a frame is offered without it.** A wash of colour blended into the page under a framed picture (a stain, a tint) counted as another picture of its unit, which made the unit a composition and took the whole region, frame and paperclip with it. The wash no longer counts, and the picture is taken from its own pixels.
- **Splatters blended into a tinted page, and specks of black ink, are hidden too.** A raster blended into the page is judged by its own pixels, where the ink lies on white and not on the page's tint. A few specks of black ink on a clear ground (0.2%-1.6% of the raster) are decoration; a line drawing with as many small marks is not.
- **A strip of light paper with writing on it is a box of text.** A plain card of light paper that the page's text lies on is offered with the boxes of text even when the text covers little of it (a strip with writing turned on its side). The same holds for a note on light paper whose middle is mostly under the page's text, however torn its edges and stained its paper.
- **A note that a larger note lies over is cut to what shows of it.** A card of text that a card painted later covers by 40% or more is rendered through its own clip with what lies over it cut out, so that it is clear which note is meant.
- **A picture painted twice on a page is not one region that holds everything between its places.** The scoreboard of a match, painted at the top of a page and again at its foot, was taken as one picture whose box held the page's text between them. A single picture is now taken where it is first painted (together with copies that lie on it or against it).
- **A vector drawing is cut to the drawing, not to the patch of paper under it.** A shape that holds all the others of a cluster and is two and a half times their area (the patch of paper at a page's corner, which reaches past the page's edge) is left out of the figure: the sticker of the vault boy in the corner of a page was offered with white margins above and to the right of it. How much of the page a figure is, and what covers it, are still judged by the cluster with its plate.
- **A banner with a title on it is not offered at all.** A flat plate (a blank raster, or a deviation of at most 6) under a good part of the page's text, nearly all of which is headings (the title of a chapter on a band of colour), is neither a picture nor a box of text. A box that has paragraphs among its text, and handwritten notes whose lines the layout takes for headings, are not banners.
- **A vector drawing that is only text is not offered as a box of text.** A figure of vector shapes that was recognised as writing from its pixels (a sidebar cut off by the edge of its shapes) is hidden, instead of being offered as a box of text with part of the sidebar missing.
- **A typed document in a raster (a telegram, a letter, a report) is offered with the boxes of text.** A raster with six or more long lines of letters (20 or more letters across at least 40% of the width, at least 0.3 of all its lines of letters), spread over at least 40% of its height, and not strongly coloured, is a document whose writing is in its pixels, like a form. Drawings in hatching, plates with a map and covers are not. Two narrower rules take what that one misses: a handful of long lines in large print on light paper (a handout with a logo under its text), and a document on a dark or grey ground (a certificate): about twenty lines, five or more of them wide, hardly any light pixels, edges along the axes.
- **More specks and blots of ink are hidden.** A raster that is all paper but a few specks of dust (at most 0.3% ink), and a blot of black ink with a hundred droplets whose edges fade into grey, are decoration. A line drawing with a handful of small marks is not.
- **A note drawn from several pieces is imported whole.** One piece of the note was offered, cut off where its edge ran through the writing, while the rest of the note had been taken for a backdrop because the page's text covers it. When the page's text crosses most of the piece's edge, the piece is grown to the box of the note that holds it.
- **A card of text with a photo pinned to it is imported without the photo.** The photo is offered by itself, so the card is what remains of its box once the photo that spans its width and lies flush with its top or bottom edge is cut away.
- **Strips of tape and stains laid over a page are not offered as boxes of text.** A raster blended into the page with a bit of text under it was marked as holding text, so it showed up in the sub-tab of images with text; it is a decoration and is hidden again.
- **A box of text on a smooth panel is not offered as a picture.** A note, a letter or a sidebar rendered with the page's text over at least half of its box, with text on its middle (the classifier found a card of text there; a yellow parchment note with handwriting is a case), is hidden whatever its look. A cut-out that the text wraps around is not a box of text. A panel with a strong tint is now taken into account too. A box with less text and a look of its own is still offered.
- **A picture stored in two overlapping halves is imported whole, from its own pixels.** A map cut into two rasters that lie side by side with the same top and bottom and overlap at the seam by up to 15 points was offered as two images. The halves are now stitched, the overlapped columns of the right one dropped, so the map comes without the page's text, numbers and labels. Two drawings that stand side by side on the same tint are told apart when only the soft edges of their ink meet (a share of a percent of their inked area), where a fixed number of shared points joined them.
- **A figure that the page paints twice, or that lies beside a card of text, is imported without the page's text.** A raster painted a second time over the same box (the same picture, painted again to blend it) counted as a second picture of its unit, and a render of the unit then carried the text of the page. It no longer does, and a picture that runs to the page edge is told apart from a card of text the classifier found over it, whatever share of its box the page's text blocks cover.
- **A card of text lying over a figure is told apart from it even when its text covers a little less than a third of it.** A stat block on parchment that the classifier had already found to be a card of text (high share of the page's text over it) was joined to the figure it overlaps when its coverage was just below the limit, and the two were rendered as one image with the page's text. A raster painted a second time over the same box is no longer counted as another picture.
- **Figures drawn on white paper are imported one by one, without the page's text.** Pictures that the page multiplies onto its own tint (two figures whose rasters overlap only by their white paper) were rendered together with the text lying over them. When the inked parts of their rasters do not overlap, each is now a picture of its own, taken from its own pixels. A picture with a mask of its own (a map with a soft edge) is told apart the same way, and tiles that lie edge to edge (a row of icons) stay one picture.
- **Tinted cards of text are hidden when the layout repeats them.** A card of parchment or dark green that carries the page's text (an ability box, a rule box, a note in a column) was kept as a picture because the test for a panel of text allowed only almost colorless panels. A tinted panel is now hidden when five or more other panels of the book have the same look: the cards of a layout come in a few styles, each used again and again. A panel of a look of its own is still offered.
- **A sidebar of text that the layout repeats is not offered as a picture.** A panel of text rendered with its text on it, whose raster is found more than once in the document (the same sidebar on several pages), is the layout and is hidden even in a book that has only a few panels. A single panel of a kind (a handout) is still offered.
- **A picture stored as tiles is imported whole.** A page-wide illustration cut into rasters that lie edge to edge (the boxes overlap by a fraction of a point) is no longer split into its tiles: rasters that meet at a seam, with aligned edges and the same pixel density, are one picture.
- **The progress counter of the document analysis does not run past its total.** A unit that is split into several pictures now adds them to the total, so the counter no longer reads more done than planned.
- **A mostly blank picture under a column of text is imported without the text.** A sketch that fades out at the foot of a column (two figures on a hill, the rest of the raster white) was taken for the plain card the page puts its text on, so the region was rendered with the paragraphs, the table and a stat block that run through the column, and the lines were cut at the picture's edge. When text that cuts the picture's edge covers at least 15% of its box, such a raster is no longer taken for a card of text and is imported from its own pixels. A card whose text lies inside it is judged as before. Of twenty-three books measured, this changes two pictures: the sketch and a tilted illustration, which now comes out without the page around it.
- **A picture painted turned inside its own outline is imported straight.** A map stored upright and painted turned by a few degrees (under a clip that is the page rectangle, or a frame that is the picture's own outline) was imported as the page shows it (askew), because the picture was sampled through the clip's window. When one clip polygon covers at least 90% of the turned picture's footprint, the page is not framing the picture, so the raw pixels (straight) are taken whole, without cutting them to the clip. Frames cut out of a turned picture (a snapshot on a page) are handled as before. Of twenty-three books measured, this changes about forty pictures (their raster is now slightly larger, with the margin the clip used to hide).
- **Pictures in frames of their own are not joined because their rasters overlap.** Three floor plans stacked on a page, each in its own turned frame, a warrior beside two pictures of a forest, a creature in the water beside swirls of wind: the rasters of such pictures reach past their frames and overlap where the frames do not, so each of these pages was imported as one picture, a render of the common box with the page's text, boxes of text and scraps of the neighbors in it (and askew, when the frames were turned). Significant pictures, some of which are shown in frames (clips), are now grouped by how their real outlines overlap (the outline of a frame, the box of a picture without one): the pictures whose outlines overlap by at most a quarter of the smaller one are separate, those that overlap more stay together. Of the thirty-one PDFs measured, this changes eleven pages: the pages that showed the problem and, among the books measured, pages of notes (one page of a player's handbook now offers a note of its own) and of diagrams (four pages of one rulebook).
- **A figure standing before a multiplied panel is imported without the panel and its caption.** A portrait standing in front of a grey brushed panel that the page multiplies over its background at 30% (with the name of the figure's form in the corner) was imported as a render of the whole card: the panel, the figure and the caption. A layer painted at 25% or less counts as the faint backdrop of a figure; a large layer (at least 10% of the page) painted with a blend mode counts as one up to 35%, since a multiplied layer shows about as much at 30% as a normal one at 20%. The figure is then imported from its own pixels. Small blended pictures at 30% (a faded sketch, a stain) are judged as before. Of the thirty-one PDFs measured, this changes the pages of one book.
- **Thin drawn objects (weapons) are no longer hidden as dividers and paperclips.** A sword, a spear and a bow cut out on a transparent ground (each a picture of its own) were hidden: the long narrow ones by the rule for frames and divider strips (6:1 or more), the bow by the rule for sparse props such as paperclips (under 30% opaque pixels, under 5% of the page). Such an image is now kept when its visible pixels have a strong contrast (a luminance spread of 64 or more: 65-88 on five weapons, against 20-33 for the pale dividers of another book and 38-61 for the paperclips and scraps of four more) and it has gaps in it (under 80% opaque); an opaque or pale strip is still hidden. Of thirty-one PDFs measured, this offers (unchecked) the four weapons of one book, a hammer of another and four logos of a third.
- **A figure standing before a faded panel is imported alone.** A figure of a character (an archer, two figures of a form) in front of the misty panel the page lays behind it (a masked layer painted at 40%, with the tables or captions of the page over it) was imported as a render of the whole box: the panel, the figure, and the tables and captions on it. In a unit that also holds an opaque picture of consequence (at least 5% of the page), a large layer (10%-50% of the page) painted at 45% or less is now the figure's backdrop, not a second picture, and the figure is imported from its own pixels. A faded picture on its own, or one painted at 50%-65% (which are worth offering), is judged as before. Of thirty-one PDFs measured, this changes pages of one book.
- **Pictures that only touch are not joined.** Two figures standing next to each other, and a portrait beside the texture layers of its frame, were imported as one render when the boxes of their rasters overlapped by a few points. Significant opaque pictures that overlap by less than 10% of the smaller one are now separate pictures (pictures in frames of their own keep the limit of a quarter of the smaller one). Of thirty-one PDFs measured, this changes about twenty pages of five books (portraits, diagrams and pairs of figures).
- **The pictures of a set standing on one backdrop are no longer lost.** Two figures of characters side by side on a brushed panel of the page, or a page of armors laid out on a washed layer, were one unit; when the unit was split into pictures, only the pictures of at least 10% of the page (or judged as content) were kept, and the others, a little smaller, were dropped as leftovers of a stack. Now a picture of at least 5% of the page is kept when it lies clear of the pictures split off (at most a quarter of its box on any of them; the flush washes of the page's layout and cards of text do not count), or when it is at least three quarters as large as the largest of them. Smaller pieces and those that sit on the pictures are still dropped. Of thirty-one PDFs measured, this changes three pages: a pair of figures, a page of armors and a stack of three snapshots pinned at a slant (the third was missing).
- **A misty margin of the layout that a map lies over is no longer offered as a second picture.** A map painted over most of a large masked layer of mist (a pale wash along the page edge, cut out by a mask) was imported twice: once whole, once as a render of the strip of mist with the part of the map that shows through it. A masked layer that was only offered as a possibility is now hidden when a judged picture at least as large is painted over 75% or more of it. A picture that is smaller than the layer does not hide it. Of thirty-one PDFs measured, this changes no other page.
- **A misty corner of the layout with text on it is no longer joined to the picture beside it.** A figure along the page edge and a flush misty wash in the corner below it (the backdrop of a quote) were one unit, so the import was a render of both, with the quote and the footer of the page. A flush picture that lies mostly outside a picture of at least 30% of the page and has the page's text over at least 8% of its box is now left out of the unit, and the figure is imported from its own pixels. Of thirty-one PDFs measured, this changes one page.
- **Small pictures whose boxes overlap but whose pixels do not are imported one by one.** A rack of cut-out weapons (an axe, a hammer, a sword, a crossbow) was imported as a single render of the box of three or four of them, and the others were not offered at all: the boxes of such thin objects overlap where the objects do not. For a unit of several small, unmasked, opaque pictures that are shown upright (or mirrored), the pixels of each are now compared with those of the others as the page paints them, and the pictures that do not touch are separate pictures, each imported from its own pixels. Turned pictures, pictures in a frame, blended and translucent ones are judged as before. Of thirty-one PDFs measured, this changes one page.
- **A staff and a bow on a page of weapons are no longer hidden as dividers and paperclips.** On a page of cut-out weapons, a quarterstaff of wrapped wood (a picture twenty times longer than wide) and a bow strung with one thin line (a sparse picture) were hidden, because their contrast is a little weaker than the contrast that makes a picture a drawn object. On a page that holds at least two drawn objects, the pictures cut out the same way whose luminance spread is 50 or more are now drawn objects too, and are offered. Elsewhere the limit stays 64. Of thirty-one PDFs measured, this changes one page.
- **A white mist under small pictures is no longer taken for the picture of their unit.** A page of items (flasks, bracelets, armor pieces) with a white wash of the layout painted under them was imported as one render of the wash and the items, together with the table and the text of the page. A raster that is not translucent-looking at all but all white where it is visible (mean luminance 250 or more, no spread) is now a unit of its own, hidden as decoration, and the small pictures that lay on it are separate pictures: those whose visible pixels do not overlap are imported one by one, each from its own pixels (pictures in a frame, turned or blended are taken for opaque all over their boxes). Of thirty-one PDFs measured, this changes nine pages of one book.
- **A picture the page paints mirrored and tilted comes out the way the page shows it.** A creature painted mirrored and turned by a few degrees (the matrix of its placement has a negative determinant) came out of the raw pixels the other way round, because only the mirrored pictures that are not turned were flipped back. A mirrored picture tilted by at most 45 degrees from upright is now flipped the way the page shows it; a mirrored diagonal or sideways one is left as before.
- **The items on cards of items are offered one by one, without the text of their cards.** A page of cards of items (a knife, a rope, a pistol, a rifle, a backpack, a roll of tape), each a cut-out object on a card of text, was imported as a few renders of cards with their descriptions, and the other items were hidden: the text of a card lies over the box of the item, the card of light paper was the largest raster of its unit, and the sparse, low-contrast items looked like paperclips. Now: (1) a small card of light, plain, opaque paper with text on it and only cut-out objects lying on it is a unit of its own and hidden, and its objects are separate pictures; (2) a small picture (2%-10% of the page) with text over its box is offered for its pixels to be judged, stands alone, and is hidden again when it is opaque all over (a card or a photo under text) and kept when it is a cut-out object; (3) on a page with three or more cut-out pictures of some size and contrast, the sparse pictures beside them (down to a contrast of 20) are objects too, not dividers or paperclips. Of thirty-one PDFs measured, the references and the other books lose nothing; this changes the pages of items of two books and adds a few cut-out objects elsewhere.
- **A flush card of text is no longer imported as a picture.** A stat block on parchment at the edge of the page, with the sketch of a squad pinned to it, was imported as one render of the card, its text and the sketch (the sketch is a picture of its own and was offered as well). A flush raster that is plain (a luminance spread of 30 or less), opaque (at least 85%) and has at least 15% of its box covered by page text is now the backdrop of that text and is hidden, whether it was taken from the raw resource or rendered with its text. Of thirty-one PDFs measured, this changes two books of one series (their cards of stat blocks and pages of notes); the reference imports lose nothing. A card of text that is wanted can still be cut out from the page preview.
- **Panels of text are no longer imported as pictures in a book whose layout is made of them.** A rulebook that sets its sidebars, lists and boxes of rules on grey or teal panels had each of them rendered with its text and offered as a picture: 251 pictures, of which 184 were panels of text. A render with at least 15% of its box covered by page text on a smooth, almost colorless raster (a luminance spread of 30 or less, a saturation of 32 or less) is a panel of text; when such panels are at least a quarter of the pictures of the book (and ten or more), they are the book's layout and are hidden, lists of items and pages of notes included. A book with a few handouts (the documents, forms and notes of a story) keeps them: such books have panels in at most 19% of their pictures, against 34%-74% for the books of panels. Of thirty-one PDFs measured, the reference imports lose nothing; five books lose panels (the rulebook above keeps 68 of its 251 pictures). A panel that is wanted can still be cut out from the page preview.
- **A panel of text laid over a picture is no longer rendered into it.** A figure of a character standing in front of a dark panel of text (a masked panel painted at 90%, with a box of rules on it) was imported as one render of the figure's pieces, the panel and its text. A unit that holds such a panel (a picture with page text over it in the middle, painted translucent) and other pictures of consequence is now split: each picture is a picture of its own, taken from its own pixels, without the text; the panel is hidden. Of thirty-one PDFs measured, this changes one page, and the reference imports lose nothing.
- **A misty strip along the page edge is no longer part of a picture beside it.** A figure of a character in front of a long, flush strip of the page's layout (a pale margin 3 times longer than wide, running down the whole page edge) was imported as a render of the box of both: the strip reaches past the figure up over the table above it, so the table came with it. A strip of that kind that overlaps a picture of at least 30% of the page is now left out of the unit, and the figure is imported from its own pixels. Of thirty-one PDFs measured, this changes one page.
- **A picture painted twice on a page is turned as its upper painting is.** A map that the page paints twice (a copy turned by half a turn under it, and the picture itself a little off the straight) was imported upside down: the raw pixels were turned by the first painting, which lies underneath, and not by the one that shows. The turn and the mirroring of a raw picture now follow the painting that lies on top (the last in the paint order). Of twenty-three books measured, this changes the turn or mirroring of eleven pictures (most of them ornaments) and the map of one adventure.
- **A picture pinned at a slight angle comes out upright, not as a skewed cut.** A picture that the page turns by a few degrees and shows through a window tilted by a degree or more (a snapshot, a photo stack) came out as the raw raster cut by the tilted outline: a skewed picture with transparent corners. A window that is one polygon filling at least 90% of its bounding box is now treated as a rectangle, and the picture is cut out of the raw pixels through it, upright, as for a window that is exactly axis aligned. Where that does not apply, a cut that leaves a quadrilateral turned by a couple of degrees is trimmed to the largest upright rectangle inside it when that rectangle takes at least 90% of the visible area and the picture fills its frame (at most 2% see-through pixels); a figure cut out on a transparent ground, a silhouette or a torn shape keeps its cut, so that a snout or a tail that reaches into a slanted corner of the frame is not trimmed away. Of twenty-three books measured, this changes pictures of seven books.
- **A sheet of paper blended over the page is no longer offered as an illustration.** A large picture cut out by a mask (a torn edge) that the page paints with a blend mode at 70%-90% opacity is a texture of the page's design, but it was taken for an illustration that fills a third to seven tenths of the page, and its region (with the page's text, photos and the part below the page) was offered. Such a picture is now hidden; an illustration painted opaque is offered as before. The blended-drawing rule of the next entry applies to opaque pictures only (a stamped paper at 70% opacity is not a drawing). Of twenty-three books measured, this changes pictures of two books only (their sheets of aged paper).
- **A drawing the text wraps around is no longer hidden as a background.** A sketch of a shirt with the text of the page flowing past it, and a helmet with the text beside it, were hidden because the boxes of the text blocks (rectangles) lie over a third of their own boxes and the picture was taken for a background with paragraphs on it. An opaque picture of at least 3% of the page that the page paints with a blend mode (a drawing on the paper, its white ground left out) is now offered, unchecked, and its raw pixels are taken, without the text beside it. Tiny pictures (bullets, icons), translucent ones and ones painted without a blend mode are judged as before.
- **A large picture that touches the page edge is no longer taken for a background.** A pair of archers on the foot of a page (a raster of 64% of the page that reaches past its left edge by one point and has text boxes over its empty top) was hidden as a full-bleed background. The limit of a picture "flush with the edge" went from 60% to 70% of the page: such a picture is judged by a higher text coverage (40%) and is otherwise offered. Of twenty-three books measured, this offers five more pictures (illustrations of three books and one page of text with a black circle, which can be deselected).
- **A picture the page paints mirrored is no longer imported the other way round.** When the page paints a picture with a negative scale (the raster is stored mirrored and the page turns it back), the raw resource was taken as it is stored, so the imported picture was a mirror image of what the page shows: a rank of figures in the wrong order, a landscape with the tree on the wrong side, and, with two pieces of one picture, pieces that did not meet at their seam. The raw pixels are now mirrored the way the page mirrors them (left to right, top to bottom, or both) before the picture is cut, rotated and joined. Of twenty-three books measured, 127 pictures in 14 books were stored mirrored, most of them ornaments and borders; the illustrations among them (a spread of a landscape, a rank of figures, a banner) now match the page.
- **Two pieces of one illustration that meet side by side on a page are joined.** A drawing of a rank of figures was stored as two pictures that touch at the middle of the page (the right edge of the left one lies within a point or so of the left edge of the right one, with the same top and bottom) and was imported as two images. The joining that was done for the halves across a spread now also applies to such a pair on one page, but only to pieces that touch or overlap by a few points (a row of portraits with a gap of a few points between them is not one picture). Because the drawing fades out to paper at the cut, a seam with next to no drawing on it (at most 10% of its rows) counts as continuous here; a seam where both sides carry drawings that do not match still keeps the pieces apart.
- **The white around a drawing on a blended sheet is no longer cut into a polygon.** A sketch of a banner on a white sheet, painted with the multiply blend mode under a clipping polygon that follows the page layout, came out with the white ground cut along that polygon (a hard, slanted edge that shows against any dark background). For a picture that is mostly white paper (at least half of its pixels) and is painted with a blend mode, what the clip hides is now filled with white paper instead of being made transparent, so the picture is a plain rectangle like the other drawings of the page. Pictures that are not mostly white keep the transparent cut. Of twenty-three books measured, this changes the sketches of one book (24 pictures) and a few splatters, scratches and drawings on white in three others (15 pictures).
- **A small ornament beside an illustration no longer pulls the text of the page into it.** A full-width illustration with a small repeated ornament (2-4% of the page) painted mostly below it, over the heading and the paragraph that follow, was imported as a render of the region that reaches down to the ornament, so the heading and the first line of the paragraph came out inside the picture. In a unit whose representative fills at least 20% of the page, a small picture (below 5% of the page, not cut out by a mask, not a backdrop) with less than half of its box on the representative is now left out of the unit, so the illustration is taken from its own pixels. Tape or a clip lying mostly on a photo still belongs to it. Of twenty-three books measured, this changes eight pictures: five in the book that showed the problem, one in a handout (two small scraps beside a photo) and one in an adventure (a plaque under an illustration).

## [0.4.1]

### Added

- **Drawings made of vector paths can be offered (module setting).** A cartoon figure drawn as vector paths (the blue vault dwellers beside the attribute descriptions of a rulebook), a diagram, a logo has no raster in the PDF, so nothing of it was ever offered; only wide rectangular fills (maps) were looked for. With the new module setting **Import vector drawings** on, the filled paths that are not rectangles are collected, and a cluster of at least 15 of them that lie within 3 pt of one another, fill their box and make a figure of 1%-50% of the page (not a table or a banner: at most 5 times longer than wide and at most 78% of the page's width) is rendered and offered as an undecided picture, unchecked. A drawing that a picture offered on the page already covers, one that is found at the same place on three pages or more (a running ornament) and one whose render is white over 80% of its pixels (a header plate on an empty page) are left out. The text of the page that runs past a drawing is painted over in the render wherever no shape of the drawing lies, with the color of the page around it; a scrap of text can remain where a wide shape lies over it. On a rulebook with a hundred figures of this kind all of them come out; the other books of a set of twenty-two add a handful of diagrams, logos and tables. With the setting off (the default) the PDF is analysed as before.
- **An illustration split in two by the gutter of a spread is joined.** One picture that runs across two facing pages (a painter with a book in his hand on the left page and the book on the right one, a double-page panorama, a dragon across the fold) was imported as two halves. The joining that was done for the halves of a map (big translucent panels) now also applies to the halves of an illustration: a picture that reaches the right edge of its page and one that starts at the left edge of the next page, with the same top and bottom, are joined when their pixels go on across the seam (something is drawn on both sides in the same rows, and the colors change across it no more than they change inside the pictures). Two unrelated pictures that merely meet at the gutter (two portraits, a board and a sheet of paper) are kept apart. The right half need not be offered by itself. Pairs that this cannot tell apart, such as two full-page scans of facing pages, may still be joined.

### Changed

- **Polish letters in the window title are drawn in the same typeface.** The display font of the window title and of the empty-state heading (Caprasimo) has no ą, ć, ę, ł, ń, ś, ź, ż, so the browser drew them in a system serif font, which looked wrong inside a word. Those two texts now use the bold weight of Figtree, which the module already ships and which covers them; the unused Caprasimo files and license text were removed.

### Fixed

- **A portrait and the card of text laid over it are imported separately.** A character's portrait with a parchment holding the stat block over its lower part was imported as one picture (the portrait, the parchment and the paragraph of the page between them). A unit that holds a card of text (at least 30% of its box covered by the page's text) and a picture of at least 10% of the page that the card covers only in part is now split into the picture and the card. A picture that lies on the card (a photo on a newspaper clipping, a signature on a sheet) leaves the card whole.
- **A card of text is imported with the ornaments of its frame that stick out of it.** A box of rules on parchment has a title plaque across its top edge and a flourish across its bottom edge; the render of the card was cut exactly at the card's box, so the title ("MAGIA") and the flourish came out cut in half. The region of a card of text now takes in small decorations that straddle its top or bottom edge (at least 30% inside the card, within 50 pt of its edge and 25 pt of its sides), except those that come within 30 pt of the edge of the page (running headers and footers).
- **Chapter openers with an illustration under a title banner are imported alike.** The illustration of one opener page came out alone (from its own pixels) and that of the next with the frame, the banner and its title, depending on whether the three masked pieces of the banner (a left cap, a plaque, a right cap) each had 5% of the page or just under it: the pieces grow with the title. In a unit whose main picture fills half the page or more, masked pieces of 4.5% of the page now count as pictures of their own, so the unit is split and the illustration is taken alone. Units under a smaller picture (a photo with a note and tape) are judged as before.
- **A layer with next to no visible pixels is no longer offered as a picture.** The glow of a flaming sword painted as a separate layer over an illustration, in a raster of the illustration's size, was offered as a second picture that showed a few specks on a transparent field. An image with fewer than 2% opaque pixels is now hidden, whatever its size (the two such layers of the books measured have 0.4% and 0.8%; the sparsest real picture has 3.1%).
- **An illustration is no longer imported together with the box of text beside it.** A picture of two figures with a box of rules laid over its corner was imported as a render of the page: the figures, the paragraph above them and the box. The box (a plain opaque panel with a lot of the page's text on it) counted as a second picture of the unit, which makes the whole unit be rendered. A member that is a card of the page's text no longer counts, and the picture is imported from its own pixels, without the text.
- **An illustration drawn in several pieces is imported as one picture.** The pieces of one illustration (sheets of paper, scrolls and pencils on a page) were imported separately when the largest of them reached past the edge of the page by a point: a picture that bleeds without anything speaking for it was never joined with its neighbors. A picture that reaches past the page by a point or two only now has its own reason (a flush picture) and is clustered like any other; the region of such a unit is the union of what is visible of its pieces (not of their rasters, whose transparent margins run into the margin of the page). A pale drawing that only touches the picture next to it is no longer taken for a paper vignette laid over it; a vignette must cover at least half of the picture it melts.
- **A picture painted twice is imported from its own pixels, without the frame the page draws around it.** The portrait of a character in a ring (the ring and its ornament are drawn by the page) came out framed on one page, where two pictures lay in the same place, and bare on another, where one did. A picture that lies exactly where the representative of its unit is (each covering 90% of the other) and is not cut out by a mask is that picture again and no longer makes the unit a composition to render.
- **A picture flush with the page edge and carrying a title or a caption is offered.** A picture that reaches past the edge of the page by a point or so (a column of pictures with caption banners, a chapter opener with its title across the picture, a figure cut out beside the text) was taken for a background with text on it when the title or banner covered 15% of the picture's center: the forest of a chapter opener, the figures of an adventure, the photos of a handbook were missing. A picture of less than 60% of the page that reaches past it at one or two edges (a corner) and by at most 2 pt is now taken for a background only when text covers 40% of its center (the title and banners measured cover up to 32%, sheets of paper with text 35% and more); in between it is left undecided, and the pixels of the picture decide. Print bleed (3 mm, three edges or more) is judged as before. Sheets of text that run flush with the edge may now be offered, unchecked, where they were hidden.
- **Dark, smooth illustrations are no longer hidden as smooth backgrounds.** A picture in red light, a portrait in a dim room or a smoky street is as smooth as a wash at both scales, because its gradients are small in absolute terms; the rule for smooth backgrounds hid a full-page illustration, three portraits and two rooms of a rulebook and a ship book. A smooth image with a mean luminance below 100 and a luminance spread of 15 or more is now kept; light sheets and washes and flat dark panels (spread below 15) are still hidden. The mean luminance is now measured for every extracted image.
- **A texture laid over a picture with a blend mode no longer hides the picture.** A map cut out by transparency (a cave on a dark page) was hidden because a page-sized concrete texture painted after it was taken for a picture covering it; the page composites that texture with the overlay blend mode, so the map shows through. Bindery now records the blend mode a picture is painted with (its own or its transparency group's), and a picture painted with a mode other than Normal no longer counts as covering what lies under it.
- **A page-sized dark scene is no longer hidden as a sheet of paper.** An undecided picture that fills the page and is smooth at the coarse scale was hidden as a sheet of paper, and the foggy half of a picture running across a spread went with it while the other half, slightly less smooth, was offered. Such a picture is now kept when its luminance spread is that of a picture (30 or more; the sheets of paper and washes measured are 20-22): night scenes, chapter openers, full-page art. A light page with a few dark shapes on it (a mean luminance of 200 or more) is still hidden.
- **An illustration painted twice is offered once.** An illustration at the foot of a page that the PDF paints once raw and once again cut out by a mask came out as two entries of different sizes (the raw one and a render of the cut-out copy), as on the pages of a rulebook with photos under a torn edge. A large masked picture that lies exactly where another picture of the page lies (each covering 90% of the other) is that picture again and is no longer offered; the raw one is.
- **Large illustrations cut out by a mask and running off the page are offered.** A picture that fills a third to seven tenths of the page, is cut out by a mask (rounded corners, an uneven edge) and reaches the edge of the page was taken for a scrap of the page's design and hidden: the spaceship illustrations at the foot of a page, pinned photos on a handout, concept art. They are now offered, unchecked. A picture of that kind that is mostly transparent (a blood splatter, a smudge) is still hidden, and a picture that fills the page is still taken for its background. Such a picture no longer hides the pictures under it.
- **A figure standing on a card of the layout is imported on its own.** A character standing in front of the panel with a stat block (the panel painted at 90%) was joined with the panel into one picture; only the figure that was cut off at the page edge came out alone. A big card of the layout and the figures on it are now separate pictures.
- **Every character card with a stat block is imported, not only some.** A plain panel with a stat block on it was imported as what the page shows only when the text covered 30% of it, and as the bare panel otherwise: of cards of one size, one to a page, some came out and the rest were left out. A smooth, opaque panel (up to 80% of the page, so a page background is not taken for one) with 15% or more text on it is now imported as what the page shows.
- **Small decorations on a page of many small pictures are no longer offered.** On a page laid out of small pictures and their masks (a crew list of portraits in a frame) a small undecided picture is part of the layout, as it was on pages crowded with tiny pictures.

## [0.4.0]

### Fixed

- **A picture that the page turns and shows through a rectangle is imported as the page shows it.** A painting placed on the page at a slight angle and cut by a plain rectangular window (an illustration in a text column) was imported from its raw pixels cut by the window turned the same way: a tilted frame with transparent corners. It is now sampled through the upright window at the raw resolution, so the picture comes out as the rectangle the page shows. It applies only when the window lies inside the picture; a tilted sheet or print lying on the page keeps being imported upright from its raw pixels.
- **Pictures of the same size at the same place on different pages are no longer taken for one picture.** The portraits of a set of ready characters (four cards, one portrait per page, the same size and position) were reduced to one: positionally matching pictures were treated as duplicates without comparing pixels, except for pictures filling half the page. The pixel comparison is now required from 5% of the page up; repeated small elements (frames, icons, headers) are still merged by position.
- **A dark panel of the page layout that only touches a picture no longer joins its unit.** The info panel beside a character's portrait was taken into the portrait's region, so one card came out as the portrait together with part of the table and the others as the portrait alone. A dark translucent panel is left out of a unit that has a solid picture.
- **A picture of 9.99% of the page is as much a picture as one of 10.01%.** Pictures of moderate size with no other evidence are offered as pictures from 9% of the page (it was 10%), so that equal cards no longer split into "picture" and "undecided" by a rounding difference.
- **Painted portraits are no longer hidden as smooth backgrounds.** The rule that hides a paper wash or a vignette also caught dark, softly painted portraits (as smooth as a wash at both scales), so most character portraits of a book were missing from the list. A smooth image whose luminance spread is as high as a figure's (30 or more; the washes and panels of the same book are 20-22) is now kept.
- **A map that runs across two pages is imported as one picture.** The two halves of such a map are big translucent panels (30%-40% opacity) painted over the page background; they were hidden as an overlay. A big translucent panel is now judged by its pixels: a colorful raster (a city map under a diagram) is a picture and is rendered with what is drawn on it, a dark bare texture is rendered when a drawing lies on it (checked as for the plans), and a panel with neither is still hidden. When such a picture on the right edge of one page meets one of the same height on the left edge of the next, the two renders are joined side by side into one image (listed on the first of the two pages). Light emblems, seals and illustrations painted translucent, and dark painted illustrations among text, are left alone.
- **A picture stored sideways and turned upright on the page is imported upright.** The raw picture of such a figure (a magazine cover placed turned by a quarter, tilted a little on the page) was imported as stored, lying on its side. Bindery now reads from the placement of the picture how many quarter turns the page applies and turns the imported picture the same way. Mirrored pictures and pictures with a diagonal turn are not affected.
- **Floor plans, maps and technical drawings on dark panels are imported as the picture the page shows.** The page paints such a drawing as vector lines over a translucent dark panel, so the picture found in the PDF was only the bare panel (a texture), and the plan itself was never offered. A translucent dark panel with hardly any text on it is now rendered together with what is drawn over it (checked by comparing a small render with the panel's own pixels) and offered as the picture, also when a sign sticks out of the panel (the sign comes with it); a panel with nothing drawn on it is still hidden.
- **The dark panels that the page lays behind its boxes and cards are no longer offered as pictures.** A rectangle of dark texture or gradient under a table, a sidebar or a weapon card came out as a bare texture, one for every box of the book. Recognized and hidden: a translucent panel (40%-65% opacity) with the page's text on it, a translucent dark texture whatever lies on it (a drawing, a table), and an opaque dark texture with text on it, as long as the classifier was not sure of it and the raster is opaque all over (a faint crest, a faded figure, a dark photograph and the lighter panels that are imported together with their text are not affected). A panel that merely touches a picture no longer drags it into one render: the picture is taken on its own. The picture that fills a character-sheet page (a page crowded with small pictures) and that nobody could judge is hidden as the backdrop of the sheet.
- **Re-importing a statblock no longer deletes Items you added by hand.** Every Actor and Item created by a profile import now records where it came from (the profile, the collection and a stable key of the entry). An update replaces only the Items that carry that mark, in collections whose text was found in the statblock; Items you added yourself, and Items of a collection that this statblock did not contain, stay. Actors and Items imported by an earlier version carry no mark, so the first update keeps them next to the new ones: the import reports how many there are. The new Items are created first and the old ones removed only after the Actor was updated, so a failure leaves the Actor as it was.
- **An update never silently picks the wrong Actor.** When several Actors share the name of an imported statblock, the one made from the same profile is chosen; if that is still not unique, the statblock is skipped with a warning instead of overwriting one of them.
- **A statblock with errors is no longer written.** An error found while the statblock was prepared (a mapped path that is gone, a value of the wrong type, a refused expression) now blocks the write and is listed in the report; before, the Actor was created incomplete and counted as imported. A changed type of a mapped field is found, and a changed schema of the template Actor is reported as a warning.
- **Statblocks that miss a required label are not imported by default.** They are still listed for diagnosis, unticked, with the missing labels shown.
- **A label is found even when the PDF splits its line differently.** Labels are matched on the reconstructed line, not on a single piece of text, and a value ends where the next known label of the profile starts. A label inside one piece of text ("Name: Goblin  HP: 7") now yields the value after it and no more.
- **A collection can end where its section ends.** The split rule has a new optional "section end" (a heading such as the next section's), so a section no longer swallows the sections that follow it. A statblock in which the section heading was not found leaves the Items on the Actor alone instead of treating the collection as empty.
- **Profile expressions are bounded.** Every pattern a profile uses is compiled in one place, with a length limit, a refusal of patterns whose shape can backtrack without bound (nested repetition, repeated alternatives), and a limit on the text it runs on. A profile with such a pattern fails validation and the pattern is refused at run time with a diagnostic. This reduces the risk of a profile freezing the browser tab; it does not run expressions in isolation, so a pattern that is slow in another way is still slow.

### Added

- **"Rotate left" and "Rotate right" in the image editor.** The window that opens from a thumbnail (preview and erase) turns the whole picture by a quarter turn. Each turn is one undo step (Ctrl+Z), "Restore original" turns the picture back before restoring its pixels, and the saved image takes the new size.
- **Arrow keys move through the images in the review.** With an image highlighted, ↓ and ↑ move the highlight to the next and the previous image of the list shown (switching the page preview when the image is on another page). Inside a field or a drop-down list the keys keep their usual meaning.
- **A "Sort images by page" setting.** In the module settings, next to "Add a white background to images". Off (the default) keeps the review list as it was: the images Bindery is sure about by page, then the undecided ones from the largest to the smallest. On, every image is listed in the order of the book, page by page and on a page from the top to the bottom, left to right.
- **The statblock engine for authoring modules gains `prepareStatblock`, `normalizeRectToBlock` and `validateProfileAgainstSchema`.** `prepareStatblock` runs the whole preparation of one statblock (extraction, casting, building, every diagnostic, and whether it may be imported) and is what the review and the import both use, so what an authoring tool previews is what is imported. `normalizeRectToBlock` turns a rectangle on the page into the block-relative form that a region source reads. The contract version is unchanged.

An image with no transparency is left untouched. It applies to every image, tokens and statblock portraits included; an image that you changed by hand (token panel, image editor) keeps what you did and gets no background at save.
- **"Fill background" in the image editor.** Puts the chosen color behind the whole picture, so that a sketch exported with a transparent background can be read. One undo step, like the erase tools.

### Fixed

- **Watermark crests are imported without the page text that lies over them.** A crest or emblem painted faintly (10%-20% opacity) behind a quotation or a text column used to be rendered together with that text. Such a translucent picture is now taken from the PDF as it is (the clean mark, unchecked "undecided" as before); the text is not part of it.
- **A paper splatter or stain that runs off the page is no longer imported as a piece of the page.** An undecided picture that bleeds off the page and has no text in its centre used to be rendered together with the body text that flows over its edge. It now comes out as the picture itself.
- **Photos pinned as strongly tilted prints no longer come with the white print border.** The more a print is tilted, the more of its mask is black, so photos tilted by more than about 10 degrees were still rendered as a rectangle of the page. Bindery now also recognizes a mask that is a tilted rectangle (by its shape, not only by how white it is) and takes the original photo. Masks with a different shape (a silhouette, an oval, a torn edge), and prints with a page text lying over them, are rendered as before.
- **A photo with a faint crest behind it is imported as the photo.** When a translucent crest laid under a pinned photo was larger than the photo, the crest decided how the unit was extracted and the photo came out with the page around it. The photo now represents the unit.
- **PDF documents and their workers are released after use.** Every analysis step opened the PDF in its own pdf.js worker and never closed it, so each import left several workers (each holding the whole file in memory) running until the page was reloaded, and repeated imports piled them up. Each step now releases its document as soon as it is done, also when it fails or is cancelled, and the bookmarks are read from the document that is already open. Measured in a browser on a short test file: after file inspection, statblock detection, image extraction, the review build and the page preview the old code left 10 workers running, the new code 0.
- **A picture cut from a larger sheet is taken as the page shows it.** Some layouts paint a figure from an image that holds several figures and let a clipping path hide the rest, so the original showed a piece of the neighbor that is not on the page. Bindery now reads the clipping paths and applies them to the original image: what the page hides becomes transparent and the result is cropped to what is visible. Many photos come out a few percent tighter for the same reason: the page shows less of them than the original holds.
- **Cut-out figures no longer come with the text around them.** A figure on a transparent ground is placed in a box that is larger than the figure, and the page text that runs around it lies in that box. It used to make Bindery render the page region together with the text. It now takes the figure itself, also when the text is a heading or a sidebar and when a colored backdrop shape stands behind the figure. A faded paper vignette laid over an illustration is not taken for the illustration, and the illustration is rendered without the strip of page that the vignette adds around it.
- **A picture painted a second time over itself at reduced opacity is no longer offered twice.** A tinted copy of the same artwork at 20%-60% opacity is part of that picture. The limit for "painted translucent" now also covers 0.6 as PDF stores it (0.600006).
- **Chapter-opener banners are no longer offered as images.** The halftone layer behind "Chapter N" is a small masked raster painted at 20% opacity (up to 6% of the page, 300 px on the long edge). Such a faint layer is now treated as decoration. Faded pictures painted at 30% and more (emblems, watermarks) are not affected.
- **Every map of a map set is offered, not just the first.** Full-page pictures of one size at the same place on every page (a booklet of maps, one to a page) were taken for repeats of the first one and merged with it. A picture that fills half the page or more is now a duplicate of another only when its pixels are identical.
- **The print hidden under another print is no longer offered.** A tilted print lies in the box of the whole rotated raster, so a print that the one on top covers almost completely (the white border and the shadow are all that shows) was not covered enough by the boxes. The check now uses the part that the mask lets through. This also hides four such back prints in a second rulebook, each a picture that is not on the page.
- **Torn paper scraps under a handout are no longer offered.** An opaque, light, flat and smooth picture that could not be classified (the scrap the crest or the note is drawn on) is hidden like other smooth backgrounds. Dark pictures that are as smooth are not affected.
- **Paper sheets under the text are no longer offered.** The torn sheets that a page lays its text on (80%-95% opaque because of their ragged edges, light and smooth) are hidden like other smooth backgrounds; the rule now looks at the visible pixels only.
- **Background removal in the token panel works on pictures with a white background.** A sketch on white is 83%-95% background, which the safeguard against a runaway flood fill (60% of the picture) took for a failed detection: the removal was cancelled and the white came back, also after a manual click on an extra area. The limit is now 98.5% when the four corners are white.
- **Black torn edges along the page are no longer offered.** A raster whose visible pixels are all black (the ragged black border of a page, a shadow) is hidden like other backgrounds.
- **Figures cut out against the page edge are offered again.** A masked figure that overhangs the page by a point or two was taken for a paper scrap or a stain that runs off the page and hidden. When its mask is a silhouette and the picture has real colors (not a splatter, smoke or a faded vignette), it is now offered.
- **Figures standing on colored panels are imported one by one, without the panel.** On a page where several figures stand on faint colored shapes, the shapes used to be offered as images of their own, or one of them stood for the whole group and the figure came out with its panel and the text around it. The faint shapes (20% opacity) are now left out of the unit and the figures are offered separately, as the figure alone.
- **A picture covered by a much larger one is hidden, a picture covered by a vignette is not.** Only a covering picture that is masked, page-sized or at least twice as large hides what is under it.

## [0.3.2]

### Fixed

- **Pictures next to page-edge pieces are no longer extracted with the page around them.** In some rulebooks a photo sits beside a coloured tab or a corner ornament that runs off the edge of the page. Bindery used to merge such a piece into the photo's unit, so the extracted image grew to the page edge and picked up the text and margins in between. These pieces now stay separate (offered as unchecked "undecided" images) and the photo is cut out on its own.
- **Pictures cut by page text now come out clean.** When a picture is partly covered by the page's own text (for example a portrait with a caption laid over its edge), Bindery used to render that page area and so copied the text into the image. It now takes the original image from the PDF instead, when that image has the same proportions as the place it is drawn in. The original has no frame or mask shape, and a picture whose original does not match what the page shows (a texture under a shape) is still rendered from the page as before.
- **Photos pinned to the page as tilted prints are extracted as the photo itself.** A photo with a tilted edge, a white print border or a drop shadow used to be cut out as a rectangle of the page, so it came with the page background, the margin strip and a neighbor's text. When the photo's mask lets most of it through and the original image has the proportions of the place it is drawn in, Bindery now takes the original image from the PDF (full resolution, no print border). A mask that hides a large part of the picture still gets the page render.
- **Paper scraps, stains and shadows that run off the page are no longer offered as images.** These pieces of the page's own design (a masked picture that bleeds off the page) used to show up as unchecked "undecided" images that were just a piece of the page with its text. They are now treated as decoration.
- **Taking the original photo now also works in the browser.** The PDF library hands decoded images over a few milliseconds after a page is read, and Bindery used to look for the mask of a photo before it had arrived, so in Foundry the photos pinned to the page as tilted prints were still rendered together with the page around them. Bindery now waits briefly for the images it needs.
- **The right image is taken from the PDF.** The library numbers images differently when pages without pictures are skipped, so an image could be mistaken for another one on the same page (a strip of paper or a mask instead of the photo). Bindery now reads the image's number from the page's own drawing list.
- **Pictures that overlap on a page are offered one by one.** Photos pinned to a page, stacked and overlapping, used to be merged into one unit and rendered as a whole block of the page (or, with the original photo taken, the others disappeared from the list). Now each photo or note that covers a real share of the page is its own image, and the tape, crests and paperclips on them stay with the picture they are on.
- **Text that lies on a picture stays with it.** A paper note or a newspaper handout is the blank paper in the PDF and the text is drawn by the page, so taking the original image gave only the background. Pictures with text over them (30% or more of their area) are rendered as the page shows them.
- **Tape, translucent ornaments and paper backgrounds are no longer offered as images.** Small elongated masked scraps (strips of adhesive tape), ornaments painted at 10%-50% opacity (watermarks, zodiac wheels) and page-sized sheets of paper are treated as decoration. They remain available through "Select & cut".
- **The hidden bottom of a stack of photos is no longer offered.** In a stack of pinned photos the one underneath is covered almost completely (75% or more) by the one on top and is not what the page shows. In some books the same filler picture lies under every stack, so it showed up many times.
- **Paperclips and other small cut-outs are no longer offered.** Small images that are mostly transparent (a paperclip, a pin) are treated as decoration.
- **Character sheets no longer fill the list with their label bars and boxes.** Images below 0.5% of the page that could not be classified are not offered, and on a page with a crowd of such images (a character sheet) its other small undecided parts are not offered either.

## [0.1.0]

### Added

- **PDF image import:** images can be imported into Foundry VTT as scene backgrounds with grid alignment, illustrations in journal entries, and files ready for use as tokens.
